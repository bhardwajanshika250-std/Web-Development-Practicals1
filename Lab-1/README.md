# Lab-1: Web Application Architecture

## Aim
To understand web application architecture, course roadmap and trace a webpage request using Chrome DevTools.

## Technologies Used
- HTML5
- CSS3
- Google Chrome
- Chrome Developer Tools

## Topics Covered
1. Web Application Architecture
2. Browser-Server Communication
3. HTTP and HTTPS Request
4. DNS Resolution
5. Chrome DevTools Network Tab
6. Course Roadmap

## Procedure
1. Created a webpage using HTML.
2. Designed the webpage using CSS.
3. Opened a website in Google Chrome.
4. Opened Chrome DevTools using F12.
5. Selected the Network tab.
6. Refreshed the page and inspected network requests.

## Result
Successfully created a webpage explaining web application architecture and traced webpage requests using Chrome DevTools.
