2. Trace a Webpage Request

When a user opens a website, these steps take place:

  1. User enters a website URL in the browser.
  2. Browser finds the server using DNS.
  3. Browser sends an HTTP or HTTPS request.
  4. Web server receives and processes the request.
  5. Server may communicate with a database.
  6. Server sends an HTTP response to the browser.
  7. Browser renders HTML, CSS and JavaScript.

How to trace using Chrome DevTools

  1. Open Google Chrome.
  2. Visit any website.
  3. Press F12 to open Developer Tools.
  4. Click on the Network tab.
  5. Refresh the webpage.
  6. Click any request to see Headers, Response and Status Code.
