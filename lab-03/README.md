


# Lab 3: Responsive Multi-Card Layout Using CSS Flexbox

## 📌 Project Overview
This assignment demonstrates modern CSS layout techniques utilizing the **Flexible Box Model (Flexbox)**. It showcases how to align elements dynamically, manage spacing with gutters (`gap`), and ensure elements wrap correctly across various screen sizes.

## 🎯 Objectives
* Master one-dimensional layout management using `display: flex`.
* Implement responsive card grids that automatically adjust alignment and wrapping behavior (`flex-wrap`).
* Add micro-interactions such as subtle vertical elevation effects on hover (`transform: translateY`).

## 🛠️ Implementation Highlights
* **Flexbox Alignment:** Leverages `justify-content: center` and `gap: 20px` to maintain consistent spacing between cards without relying on rigid margin hacks.
* **Interactive Cards:** Clean white card containers featuring distinct borders, rounded corners, and smooth transition properties.
