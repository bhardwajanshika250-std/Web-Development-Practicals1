# Lab 1: Comprehensive HTML5 Semantic Structure & Modern CSS Styling

## 📌 Project Overview
This laboratory practical focuses on building a solid foundation in web development by implementing a semantically structured HTML5 web document paired with responsive, clean CSS styling. It demonstrates standard page layouts, typography principles, and visual container formatting.

## 🎯 Objectives
* Understand and implement core semantic HTML5 elements (`<header>`, `<main>`, `<section>`, `<h1>`).
* Apply foundational CSS styling rules to manage document flow, background colors, padding, margins, and text alignment.
* Maintain clean code modularity by separating structural markup (`index.html`) from presentation logic (`style.css`).
